# Fahad's Projects

## Multi-Camera Person Localization, AI Threat Prioritization and Automated Emergency Dispatch (MSc project)

A complete AI surveillance pipeline built in Python. It covers gesture classification (LSTM + SVM on MediaPipe skeletons), person re-identification across cameras (ResNet-based), a threat-prioritisation engine, a live Flask + SocketIO dashboard, automated emergency dispatch through Twilio, SHAP explanations and homography-based camera calibration.

Results: collapse detection F1 of 0.91 with precision 1.00, full-system false alarm rate of 4.1%, and 76% of collapses automatically dispatched. Re-ID rank-1 accuracy was 87.1% on Market-1501.

## RAG Chatbot (this chatbot)

A Retrieval-Augmented Generation chatbot built with Python, Flask, scikit-learn TF-IDF retrieval and the Claude API. It answers questions about Fahad using only his own documents.
